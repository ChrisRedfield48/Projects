## О проекте

Витрина JavaScript-проектов, оформленная как **редактор кода**. Сам сайт выглядит как IDE — титлбар, проводник, вкладки, номера строк, статус-бар — а проекты это буквально массив `projects` с подсветкой синтаксиса. Каждый объект кликабельный целиком и открывает живой проект; недоделанные показаны нативно как `open: null` и приглушены.

Три «файла» переключаются вкладками, как в настоящем редакторе: `projects.js` (витрина), `about.js` (мини-профиль), `contact.js` (ссылки). Есть переключатель тёмной / светлой темы — выбор запоминается.

## Как устроено

**Данные** — массив `PROJECTS`, каждый элемент:

```js
{
  name: 'Calculator',
  tag:  'JS · DOM',
  info: 'Калькулятор: события и работа с DOM.',
  open: 'https://github.com/ChrisRedfield48/Calculator',
}
```

Недоделанный проект помечается `wip: true`, а если ссылки ещё нет — `open: null`.
Добавить проект значит дописать один объект в массив.

**Рендер** — каждый объект превращается в подсвеченные строки кода (`.code-line`).
Живые проекты оборачиваются в кликабельную ссылку, `wip` без ссылки — в некликабельный блок.

**Файлы** — клик по вкладке или файлу в проводнике рендерит соответствующий код в редактор. Активный файл подсвечивается и там, и там.

**Тема** — клик по кнопке переключает класс `light` на `<body>`; все цвета живут в CSS-переменных, переключение мгновенное. Выбор сохраняется в `localStorage`.

**Счётчики** — `live` / `wip` считаются из массива автоматически, в коде не дублируются.

## Дизайн

```
Фон редактора    #0c0c0a    ░░ тёплый чёрный
Хром             #131210    ▒▒ титлбар · проводник · статус-бар
Акцент / ссылки  #E8D84A    ▓▓ JS-жёлтый
Шрифт            Fira Code  моно, лигатуры  =>  ===  !==
```

Подсветка синтаксиса:

```
ключевые слова   #c792ea   сиреневый      строки        #cbb98c   песочный
ключи            #8fbce0   голубой        ссылки         #E8D84A   золото
числа            #7fd4c4   бирюзовый      комментарии    #5f6a54   оливковый
```

Анимации: `jsflip` — логотип JS раз в ~6 c делает 3D-оборот (и крутится по наведению) · `fadeUp` — код плавно появляется при открытии файла · курсор `▮` мигает в конце файла. Всё уважает `prefers-reduced-motion`.
