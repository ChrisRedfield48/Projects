## О проекте

Витрина JavaScript-проектов в космической эстетике NIP.SYS. Фон всего сайта — **живая нейросеть на canvas**: узлы-звёзды в туманности, по рёбрам бегут импульсы (прямой проход мятный, обратный пурпурный), сцена реагирует на курсор, клик по пустому космосу даёт всплеск сигналов. Контент скроллится поверх в полупрозрачных стеклянных панелях.

Тема языка — через **JS-золото `#E8D84A`**: заголовок JAVASCRIPT с золотым градиентом, айброу `function · event loop · dom`, золотые ссылки и подсветка карточек. Недоделанные проекты показаны честно: приглушены, помечены «в разработке · скоро», без мёртвых ссылок.

Секции: герой → о разделе → проекты → контакт.

## Как устроено

**Данные** — массив `PROJECTS` в `script.js`, каждый элемент:

```js
{
  name: 'Calculator',
  tag:  ['JS', 'DOM'],
  info: 'Калькулятор: события и работа с DOM.',
  open: 'https://github.com/ChrisRedfield48/Calculator',
}
```

Если проект не готов — `open: null`: карточка приглушается, вместо ссылки — «скоро».
Добавить проект значит дописать один объект в массив.

**Рендер** — живые проекты становятся кликабельными карточками-ссылками, wip — некликабельными блоками. Нумерация только у живых.

**Счётчики** — «задеплоено / в разработке» считаются из массива автоматически, руками не дублируются.

**Движок сети** — оптимизирован под слабые GPU и Retina: туманность запекается в отдельный слой один раз (ноль градиентов на кадр), DPR канваса ограничен 1.5, свечение через кэш-спрайты. Вкладка свёрнута — анимация спит.

## Запуск

```bash
python3 -m http.server 8000
# http://localhost:8000
```

Сайт статический, без зависимостей и сборки. GitHub Pages: **Settings → Pages**, ветка `main`, папка `/root` — пушнул и готово.
